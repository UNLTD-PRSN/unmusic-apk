# UnMusic APK

Aplikasi pemutar musik untuk Android, dibuat oleh **UNLTD** dengan Kotlin dan Jetpack Compose.

Versi Windows: [unmusic-windows](https://github.com/pemula-root/unmusic-windows)

## Unduh

1. Buka halaman [Releases](https://github.com/pemula-root/unmusic-apk/releases).
2. Unduh file `.apk` versi terbaru.
3. Buka file tersebut di HP.

## Cara pasang

Karena dipasang di luar Play Store, Android akan meminta izin pemasangan dari sumber lain.

1. Saat muncul peringatan, pilih **Pengaturan**.
2. Aktifkan **Izinkan dari sumber ini** untuk aplikasi yang kamu pakai membuka file (browser atau pengelola file).
3. Kembali, lalu tekan **Pasang**.

Kalau Play Protect memberi peringatan, pilih **Tetap pasang**.

## Fitur

- Putar musik dengan antarmuka yang ringan dan rapi
- Unduh lagu untuk diputar tanpa internet
- Playlist dan antrean lagu

## Persyaratan

- Android 8.0 atau lebih baru

## Pembaruan

Versi baru dirilis di halaman [Releases](https://github.com/pemula-root/unmusic-apk/releases). Unduh APK terbaru dan pasang di atas versi lama.
